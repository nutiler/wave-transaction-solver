## Upgrade and migration

1. Keep Chrome loading the existing **extension** folder. Reload it in `chrome://extensions`, then open Wave Solver. A new unpacked path can create a new storage origin.
2. Startup saves a complete recoverable beta checkpoint before session restoration or receipt normalization. The existing IndexedDB database/store/schema stay in place. Existing feature keys and Chrome settings are retained, including directory handles, rules, queues, receipts and provider requests.
3. Confirm your selected business, current rules, queued choices and pending attempts. New rule scope binds legacy unscoped rules to their original business while keeping aliases and account/category restrictions. Historical proposal packs stay inactive and retain their source-hash requirement.
4. In **Data & setup**, export a private local backup before intentionally changing installation identity. Portable restore preserves executing/uncertain locks, refuses conflicting financial state and requires folder access to be renewed. Restoring over an empty welcome session is supported. Keep the original installation until the restored state is checked.
5. Renew access to the saved data directory if Chrome requests it. No background folder watcher or permanent filesystem permission is claimed.
