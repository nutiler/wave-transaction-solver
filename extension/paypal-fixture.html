LOCAL DATA HELPERS
PayPal download helper
Create missing All transactions reports year by year, oldest first, then collect their CSVs. Files go directly to data/paypal for the purchase solver.
Setup and collection settings
Collect PayPal reports
One click creates missing years and verifies each exact report row before waiting. It then refreshes every five seconds for up to ten minutes while collecting them. From dates are locked through the calendar before To dates are entered. A temporary report tab opens automatically and closes after everything is saved. Resume verifies saved request checkpoints against the refreshed report list and recovers absent requests. Diagnostics stay available while collecting.
Completed years use January 1 through December 31; the current year ends today. Existing cross-year and Balance affecting CSVs are saved as evidence, but annual completion requires the exact All transactions CSV range. Existing PDFs are left alone. Saved files are verified before they are skipped; changed files receive a new name.
Ready for setup.
After collecting, return to the Command center and use Refresh data folder under Optional data. Importing evidence prepares suggestions; it does not change Wave.
Advanced / download troubleshooting
The last button clears an interrupted request checkpoint only after you have checked the report list. It does not delete CSVs. ZIP reports need manual extraction into data/paypal. Controls diagnostics contain report ranges and field labels, never credentials or download URLs.
