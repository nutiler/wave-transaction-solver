Start fresh creates a new report for every year, including 2025, using January 1–December 31 for completed years. The oldest year starts at PayPal’s seven-year limit. It verifies each new submission, refreshes for up to ten minutes, and saves every ready original before importing any files. Resume continues this batch without repeating confirmed requests.

Files are kept in data/paypal. Original downloads and earlier history are preserved. After collection, use Refresh data folder in the Command center. The temporary report tab closes when all originals are saved.
