Amazon download helperLOCAL DATA HELPERS

Choose the project data folder once. All download helpers share it and sort files into service folders. Earlier versions are preserved.

Setup

Amazon downloads through Chrome. Set Chrome’s download Location to your project’s data folder once, then this helper sorts the CSV into data/amazon/business. This setting affects all browser downloads. You can also select a downloaded file below.

Amazon Business report

The helper sets both dates, presses Submit, waits for Generate report, then collects the resulting order/item CSV. The page reader waits through loading automatically. It waits up to four minutes; Resume collects a report that finishes later without generating another one.

Ready for setup.

Regular Amazon / another person’s account

Regular Amazon has a different export flow. Open Request Your Information in that person’s signed-in account and request their order data there. Keep their archive in their own project data folder; do not combine it with this business’s reports. This helper does not submit a personal data request or classify personal purchases automatically. The personal archive format needs its own importer once supplied.

After saving, return to Command center → Optional data → Refresh data folder. Only business order/item CSVs are automatically collected here.

Advanced / troubleshooting

Reset clears only this helper’s unconfirmed request checkpoint. Existing files are preserved. Diagnostics exclude email contents, account addresses and signed download URLs.
